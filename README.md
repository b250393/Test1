# 國學院大學将棋部 新歓ポスター

國學院大學将棋部の新入生歓迎（新歓）用ポスター制作プロジェクトです。

## ファイル構成

```
shogi_poster/
├── prompt.md    # AI画像生成用プロンプト（英語・日本語）
└── poster.html  # HTMLポスターモックアップ（ブラウザで確認可能）
```

## ポスターコンセプト

- **アスペクト比**: 16:9 横長構図
- **スタイル**: フォトリアル・実写風・高解像度
- **舞台**: 和モダンな大学キャンパスの畳の部屋
- **主役**: 淡い着物の女子大生 vs 作務衣の男子学生による将棋対局
- **背景**: 障子越しに神社（鳥居・社殿）＋渋谷風高層ビル群のシルエット
- **ギャラリー**: きれいめカジュアルな男子2名・スカートの女子大生2名
- **色調**: 柔らかなパステル〜ニュートラル系、自然光

## 使い方

### HTMLモックアップを確認する

```bash
open shogi_poster/poster.html
```

ブラウザで `shogi_poster/poster.html` を開くと、ポスターのレイアウトモックアップが表示されます。

### AI画像生成

`shogi_poster/prompt.md` に記載されている英語プロンプトを、Stable Diffusion・Midjourney・DALL-E 等のAI画像生成ツールに入力してください。

生成した画像は、`poster.html` の `.poster` 要素の背景画像として設定するか、`<img>` タグで差し替えることでHTMLモックアップに統合できます。最終的な印刷・配布用には、画像編集ソフト（Photoshop・Canva等）でテキストを重ねて完成させてください。
